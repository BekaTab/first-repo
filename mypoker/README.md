# mypoker.ge — ონლაინ მაღაზია

პოკერის აქსესუარების მაღაზია. შეკვეთა ხდება WhatsApp-ით; პროდუქცია, ფასები და ფასდაკლებები იმართება ადმინ პანელიდან (`mypoker.ge/admin/`).

## გაშვება (ერთხელ)

1. **Vercel-ზე ახალი პროექტი.** vercel.com → Add New → Project → აირჩიეთ `first-repo` → **Root Directory: `mypoker`** → Deploy.
   დანარჩენ პარამეტრებს (`npm ci`, `npm run build`, `dist`) Vercel თავად კითხულობს `mypoker/vercel.json`-დან.
2. **დომენის მიბმა.** პროექტში: Settings → Domains → დაამატეთ `mypoker.ge` და `www.mypoker.ge`.
   Vercel გაჩვენებთ DNS ჩანაწერებს (ჩვეულებრივ: `A` ჩანაწერი `@` → `76.76.21.21` და `CNAME` ჩანაწერი `www` → `cname.vercel-dns.com`).
3. **DNS რეგისტრატორთან.** იქ, სადაც `mypoker.ge` გაქვთ რეგისტრირებული, DNS-ის მართვაში ჩაწერეთ Vercel-ის ჩანაწერები
   და წაშალეთ ძველი `A`/`CNAME` ჩანაწერები `@`-სა და `www`-ზე. ეს ჩაანაცვლებს დომენზე არსებულ ძველ საიტს.
   გავრცელებას რამდენიმე წუთიდან 24 საათამდე სჭირდება; HTTPS სერტიფიკატს Vercel თავად აყენებს.

ამის შემდეგ ყოველი ცვლილება `main` ბრენჩზე (მათ შორის ადმინიდან გამოქვეყნება) საიტს ავტომატურად აახლებს.

## ენები

საიტი ორ ენაზეა: ქართული `mypoker.ge/` და ინგლისური `mypoker.ge/en/`. ზედა ზოლში არის გადამრთველი **ქარ | EN**, რომელიც იმავე გვერდს მეორე ენაზე ხსნის. საიტის ტექსტები ინახება `MyPokerStore.jsx`-ის `TEXT` ობიექტში. პროდუქტების ინგლისური სახელი, აღწერა და ნიშანი ადმინში შეგყავთ („ინგლისური ვერსია“). თუ ინგლისური ველი ცარიელია, იმ ადგილას ქართული ტექსტი ჩანს.

## ადმინ პანელი

მისამართი: `https://mypoker.ge/admin/` (Google-ში არ ინდექსირდება).

**პირველი დაყენება (თითო მოწყობილობაზე ერთხელ):**

1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
   - Repository access: *Only select repositories* → `first-repo`
   - Permissions: **Contents — Read and write**, **Commit statuses — Read-only**
2. გახსენით `/admin/`, ჩასვით token და მოიფიქრეთ პაროლი. Token დაშიფრულად ინახება მხოლოდ ამ ბრაუზერში.

**რისი გაკეთება შეიძლება:**
- პროდუქტის დამატება, რედაქტირება, წაშლა და რიგის შეცვლა (↑ ↓);
- კატეგორიები ორ განყოფილებად: **„პოკერი“** (წითელი) — კარტები, ჩიპები, მაგიდები, პოკერის აქსესუარები; და **„სამაგიდო თამაშები და აქსესუარები“** (ოქროსფერი) ქვეკატეგორიებით: ნარდი, დომინო, ბინგო და ლოტო, სამაგიდო თამაშები, სხვა გასართობი. ადმინში ქვეკატეგორია ჩნდება, როცა კატეგორიად „სამაგიდო თამაშები და აქსესუარები“ არის არჩეული;
- რამდენიმე ფოტო თითო პროდუქტზე (10-მდე, მაღალი ხარისხით, 2000 პიქსელამდე). პირველი ფოტო მთავარია, რიგი ისრებით იცვლება. ბარათისთვის პატარა ასლი ავტომატურად იქმნება;
- დეტალური აღწერა პროდუქტის გვერდისთვის (ცარიელი ხაზი ახალ აბზაცს იწყებს, „-“-ით დაწყებული ხაზები სიად გამოჩნდება);
- „უფასო მიწოდება N ₾-დან“ წარწერის თანხა (პარამეტრებში);
- ფასი, ფასდაკლებული ფასი და ფასდაკლების ბოლო დღე (ვადის გასვლის შემდეგ ფასდაკლება საიტზე თავად ქრება);
- ფასდაკლება მთელ კატეგორიაზე ან ყველა პროდუქტზე პროცენტით, და მისი გაუქმება;
- „მარაგშია“ / „შეკვეთით“ და „ჩანს საიტზე“ / დამალვა;
- ტელეფონის და WhatsApp ნომრის შეცვლა.

„გამოქვეყნება“ ინახავს ყველაფერს ერთ commit-ად; საიტი განახლდება დაახლოებით 1 წუთში.

## როგორ არის აწყობილი

- `products.json` — პროდუქცია და კონტაქტი (ამას ცვლის ადმინ პანელი).
- `MyPokerStore.jsx` — მაღაზიის React კოდი.
- `admin/index.html` — ადმინ პანელი.
- `public/images/` — ადმინიდან ატვირთული ფოტოები.
- `build.mjs` — აწყობს `dist/`-ს: `index.html` (პროდუქცია ჩაწერილია გვერდში), თითო პროდუქტის გვერდი `p/<id>/`, `404.html`, `sitemap.xml`, `robots.txt`, `app.js`, `app.css`, `admin/`, `images/`.

ლოკალურად: `npm ci && npm run build`, შემდეგ `dist/` ნებისმიერი სტატიკური სერვერით.

## უსაფრთხოება

- **უსაფრთხოების ჰედერები (`vercel.json`):** Content-Security-Policy ბრაუზერს მხოლოდ საიტის საკუთარი სკრიპტების გაშვებას აძლევს. ადმინს შეუძლია მხოლოდ GitHub API-სთან დაკავშირება. საიტის სხვა გვერდში ჩასმა აკრძალულია (clickjacking-ისგან დაცვა). ჩართულია HSTS, nosniff და Referrer-Policy.
- **ტექსტის უსაფრთხო ჩვენება:** პროდუქციის მონაცემები გვერდში ჩაიწერება როგორც `application/json` და არა როგორც შესრულებადი სკრიპტი. ყველა ტექსტი (სახელი, აღწერა, ნომერი) ჩანს როგორც ჩვეულებრივი ტექსტი. WhatsApp ნომრიდან ყველაფერი, ციფრების გარდა, იშლება.
- **ადმინის token:** ბრაუზერში ინახება PBKDF2 + AES-GCM დაშიფვრით, მხოლოდ თქვენი პაროლით. ღია სახით მხოლოდ მიმდინარე ჩანართში ინახება, 4 საათით. გამოიყენეთ ძლიერი პაროლი და token-ს მიეცით ვადა (მაგ. 1 წელი). თუ მოწყობილობა დაიკარგა, GitHub-ში token წაშალეთ (Settings → Developer settings → Fine-grained tokens).
- **token-ის უფლებები:** token-ს `first-repo`-ზე ჩაწერის უფლება აქვს, ამიტომ EIB-ის საიტის შეცვლაც შეუძლია. ის მხოლოდ თქვენს მოწყობილობებზე გამოიყენეთ. ასევე ჩართეთ GitHub-ში ორფაქტორიანი ავტორიზაცია (2FA).
- **ფასი შეკვეთისას:** მყიდველს შეუძლია WhatsApp-ის შეტყობინების ტექსტი შეცვალოს, ამიტომ შეკვეთის დადასტურებისას ფასი ყოველთვის ადმინში ან საიტზე გადაამოწმეთ.
