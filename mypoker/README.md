# mypoker.ge — ონლაინ მაღაზია

პოკერის აქსესუარების მაღაზია. შეკვეთა ხდება WhatsApp-ით; პროდუქცია, ფასები და ფასდაკლებები იმართება ადმინ პანელიდან (`mypoker.ge/admin/`).

## გაშვება (ერთხელ)

1. **Vercel-ზე ახალი პროექტი.** vercel.com → Add New → Project → აირჩიეთ `first-repo` → **Root Directory: `mypoker`** → Deploy.
   დანარჩენ პარამეტრებს (`npm ci`, `npm run build`, `dist`) Vercel თავად კითხულობს `mypoker/vercel.json`-დან.
2. **დომენის მიბმა.** პროექტში: Settings → Domains → დაამატეთ `mypoker.ge` და `www.mypoker.ge`.
   Vercel გაჩვენებთ DNS ჩანაწერებს (ჩვეულებრივ: `A` ჩანაწერი `@` → `76.76.21.21` და `CNAME` ჩანაწერი `www` → `cname.vercel-dns.com`).
3. **DNS რეგისტრატორთან.** იქ, სადაც `mypoker.ge` გაქვთ რეგისტრირებული, DNS-ის მართვაში ჩაწერეთ Vercel-ის ჩანაწერები
   და წაშალეთ ძველი `A`/`CNAME` ჩანაწერები `@`-სა და `www`-ზე. ეს ჩაანაცვლებს დომენზე არსებულ ძველ საიტს.
   გავრცელებას რამდენიმე წუთიდან 24 საათამდე სჭირდება; HTTPS სერტიფიკატს Vercel თავად აყენებს.

ამის შემდეგ ყოველი ცვლილება `main` ბრენჩზე (მათ შორის ადმინიდან გამოქვეყნება) საიტს ავტომატურად აახლებს.

## ადმინ პანელი

მისამართი: `https://mypoker.ge/admin/` (Google-ში არ ინდექსირდება).

**პირველი დაყენება (თითო მოწყობილობაზე ერთხელ):**

1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
   - Repository access: *Only select repositories* → `first-repo`
   - Permissions: **Contents — Read and write**, **Commit statuses — Read-only**
2. გახსენით `/admin/`, ჩასვით token და მოიფიქრეთ პაროლი. Token დაშიფრულად ინახება მხოლოდ ამ ბრაუზერში.

**რისი გაკეთება შეიძლება:**
- პროდუქტის დამატება, რედაქტირება, წაშლა და რიგის შეცვლა (↑ ↓);
- ფოტოს ატვირთვა (ავტომატურად მცირდება 1200 პიქსელამდე);
- ფასი, ფასდაკლებული ფასი და ფასდაკლების ბოლო დღე (ვადის გასვლის შემდეგ ფასდაკლება საიტზე თავად ქრება);
- ფასდაკლება მთელ კატეგორიაზე ან ყველა პროდუქტზე პროცენტით, და მისი გაუქმება;
- „მარაგშია“ / „შეკვეთით“ და „ჩანს საიტზე“ / დამალვა;
- ტელეფონის და WhatsApp ნომრის შეცვლა.

„გამოქვეყნება“ ინახავს ყველაფერს ერთ commit-ად; საიტი განახლდება დაახლოებით 1 წუთში.

## როგორ არის აწყობილი

- `products.json` — პროდუქცია და კონტაქტი (ამას ცვლის ადმინ პანელი).
- `MyPokerStore.jsx` — მაღაზიის React კოდი.
- `admin/index.html` — ადმინ პანელი.
- `public/images/` — ადმინიდან ატვირთული ფოტოები.
- `build.mjs` — აწყობს `dist/`-ს: `index.html` (პროდუქცია ჩაწერილია გვერდში), `app.js`, `app.css`, `admin/`, `images/`.

ლოკალურად: `npm ci && npm run build`, შემდეგ `dist/` ნებისმიერი სტატიკური სერვერით.
