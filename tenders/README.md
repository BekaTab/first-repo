# სახელმწიფო შესყიდვების მონიტორი (Streamlit)

ერთფაილიანი აპლიკაცია (`app.py`), რომელიც იღებს ტენდერებს
[tenders.procurement.gov.ge](https://tenders.procurement.gov.ge/)-დან და იძლევა მათი ძებნის,
ფილტრაციისა და Excel/CSV ექსპორტის საშუალებას.

```bash
cd tenders
pip install -r requirements.txt
streamlit run app.py
```

- მონაცემები ქეშირდება 15 წუთით (`@st.cache_data`); „🔄 მონაცემების განახლება“ ასუფთავებს ქეშს.
- ფასის, CPV-ის, შემსყიდველის, სიტყვისა და სტატუსის ფილტრები მყისიერია (ლოკალურად მუშაობს).
- თუ საიტი მიუწვდომელია, ⚙️ პარამეტრებში ჩართეთ **დემო რეჟიმი** (გამოგონილი მონაცემები).
